# Session: K3s homelab rebuild (June 2026)

Rebuilt the `netbug_k3s` repo from scratch on branch `rebuild-2026` (old
history preserved on `master`). Designed and scaffolded the full GitOps
structure plus the matching Cloudflare exposure layer in `nb3_tf`.

## Decisions

- **Flux CD v2.8** GitOps monorepo: `clusters/homelab` → ordered Kustomizations
  `infra-sources → infra-crds → infra-controllers → infra-config → apps`.
- **Gateway API v1.5.1 (Standard, vendored CRDs) + Traefik v3.7** managed by
  Flux — k3s-bundled traefik/servicelb/local-storage disabled in
  `/etc/rancher/k3s/config.yaml` (modern config-file idiom, embedded etcd via
  `cluster-init` for future server joins, flannel vxlan on trusted LAN).
- **Dual access path, one hostname**: Cloudflare Tunnel (in-cluster cloudflared,
  remote-managed config) for public + Mikrotik split-horizon DNS → MetalLB VIP
  for LAN. `always_use_https=on` stays (SSH tunnel WSS) ⇒ Gateway must always
  hold the cert-manager wildcard `*.nb3.me` cert; HSTS deferred.
- **Storage split**: Longhorn (1→2 replicas at M7) for app state; large media
  stays on the media node's disk, exported over NFS `ro`, consumed via
  csi-driver-nfs **static PV** (hostPath rejected — pins pods).
- **Service module** = `apps/<name>/{ks.yaml, app/{namespace,pvc,helmrelease,
  httproute,secret.sops}}` on bjw-s app-template 4.6.2 (no maintained upstream
  Paperless chart; uniform pattern). Paperless = SQLite + non-persistent Redis.
- **nb3_tf additions** (new files only, ssh_tunnels.tf untouched): one shared
  `k8s-homelab` tunnel + `k8s_services` map → ingress rules with
  `origin_server_name`/`http_host_header` (verified HTTPS to the Gateway, no
  noTLSVerify) + proxied CNAMEs + `k8s_tunnel_token` output. TCP ingress
  `k3s.nb3.me` for remote kubectl (TCPRoute still Experimental → not Gateway).

## Key takeaways

- Two-node clusters should be 1 server + 1 agent: 2-member etcd has quorum 2
  and is strictly worse than 1; embedded etcd still worth enabling day one.
- Flux Kustomization layers (`dependsOn`) replace Helmfile ordering; CR
  instances (MetalLB pools, ClusterIssuer, Gateway) must live a layer after
  the controllers that own their CRDs.
- cloudflared with `config_src=cloudflare` needs only TUNNEL_TOKEN in-cluster
  (base64 json {a,t,s}); ingress rules live in Terraform — one place to add
  a service hostname.
- HTTPRoute hostname matching across the tunnel requires
  `origin_request.http_host_header`; with a valid wildcard cert on the
  Gateway, `origin_server_name` makes the CF→origin hop verified TLS.
